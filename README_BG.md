# LEGO Collection Manager 2.1.6 — Подредени липсващи части

## Ново в 2.1.6

- В **„Общи липсващи части“** частите се подреждат **първо по цвят**, **после от малки към големи** (според размерите, когато са посочени в името), и **накрая по номер**.
- При част без достатъчно информация за размера тя се подрежда след размерните части **от същия цвят**. Това не е физическо измерване на всяка LEGO форма.
- Ако количество се промени, при обновяване на списъка частите автоматично заемат правилното място. Изчезват от списъка, когато вече не липсват.
- Запазени: търсене по име и номер; филтри по цвят, размер и вид; миникартите на комплектите с липсващите количества; отметката за липсващи резервни части.
- Резервните части се показват **отделно**, когато се включи отметката, и се подреждат по същия начин. Инвентарните изгледи „Таблица“, „Карти“, „Книжка“ остават както в 2.1.5.
- Базата SQLite и данните **не се мигрират и не се променят** от тази функционалност.

## Тест през Python (без EXE)

1. Затвори версия 2.1.5 и архивирай текущата папка `data`.
2. Разархивирай този проект в нова папка.
3. Копирай **копие**, не оригинала, на `data` в `lego_216/data`.
4. Стартирай `main.py` от `lego_216`, както обичайно: `python main.py`.
5. Отвори „Общи липсващи части“, провери цветовете и реда на размерите, промени наличност на част и провери пренареждането; опитай и отметката за резервните.
6. Ако всичко е наред, можеш да стартираш `BUILD_EXE.bat` на Windows.

**Важно:** в публичен GitHub Release не включвай папка `data`, защото съдържа лични количества и API ключ.
